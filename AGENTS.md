## Website Development SOP

- Read `.website-sop.yml` before changing this website.
- Keep planning and architecture decisions in the configured documents.
- Run `web-sop doctor` before implementation.
- Run `web-sop check --mode fast` before handoff.
- Run `web-sop check --mode release` before production release.
- Never move existing files only to satisfy the preferred layout without an approved migration.
